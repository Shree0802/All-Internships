- Data cleaning
- Missing value handling
- Exploratory Data Analysis
- Feature engineering
- Time-based features
- Regression model development
- Model comparison
- Model evaluation
- Temperature prediction
- Interactive Streamlit dashboard

### Technologies

## 2️⃣ Spam Email Classifier

A Machine Learning and Natural Language Processing application that classifies messages as **Spam** or **Ham/Safe**.

### Key Components

- Text preprocessing
- Tokenization
- Stopword removal
- Stemming
- Lemmatization
- TF-IDF vectorization
- NLP feature extraction
- Classification
- Model comparison
- Interactive prediction interface

### Machine Learning Models

- Multinomial Naive Bayes
- Logistic Regression
- Support Vector Machine

### Technologies

`Python` `Pandas` `NumPy` `Scikit-Learn` `NLTK` `TF-IDF` `Streamlit` `Matplotlib` `Seaborn` `WordCloud`

### 🌐 Live Application
