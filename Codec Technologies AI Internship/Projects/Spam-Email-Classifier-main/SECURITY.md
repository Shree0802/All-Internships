# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within the **Spam Email Classifier**, please report it by opening an issue or emailing the maintainer directly. 

All security vulnerabilities will be promptly addressed. Please do not report security vulnerabilities through public GitHub issues.
